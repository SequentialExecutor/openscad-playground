# Editable example: rotated block

Open `rotated-block.forma3d.json` using the visual workspace's Open project.
The centered box has local dimensions 50 × 30 × 20 mm, position (15, 0, 10) mm
and a 90° Z rotation. Its world bounds are (0, −25, 0) to (30, 25, 20) mm.

`rotated-block.stl` was generated by the actual OpenSCAD/Manifold browser worker
in the automated visual editor test. Its binary STL vertex bounds were checked
against those values. The file has 12 triangles; it was not substituted with a
Three.js preview. The editable JSON contains a stable generated body ID.
